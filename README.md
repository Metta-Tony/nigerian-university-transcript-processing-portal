# DESIGN AND IMPLEMENTATION OF A WEB BASED STUDENT TRANSCRIPT PROCESSING SYSTEM

A web-based transcript request and verification portal for managing application submissions, tracking statuses, and validating student academic records.

## Languages and technologies

- **HTML** provides the page entry point and root element where the application is mounted.
- **TypeScript** implements the application logic and its data models with static types.
- **TSX (TypeScript + JSX)** builds the React interface and reusable UI components.
- **CSS** styles the application; **Tailwind CSS** supplies utility classes and the project’s styling system.
- **JSON** stores project metadata, dependencies, and tool configuration.

## Run locally

**Prerequisites:** Node.js

1. Install dependencies:
   `npm install`
2. Start the app:
   `npm run dev`
3. Open the app in your browser at `http://localhost:3000`
